# SportMatch — public assets

## icons/ (30 SVG, 24×24, stroke 2, currentColor)
Set curado derivado de Lucide (ISC). En Figma: File → Place image / arrastrar los .svg,
o importarlos como componentes. `star`, `heart` y `flame` también se usan en versión sólida
(rellenar el path con currentColor).

compass, layers, map, user, plus, map-pin, navigation, calendar, clock, users, signal,
star, heart, flame, trophy, search, sliders, x, check, arrow-right, chevron-left,
chevron-right, chevron-down, share, settings, image, pencil, log-out, bell, zap

Glifos extra usados en la app (deportes: soccer-ball, basketball, tennis-ball,
tennis-racket, footprints; auth: mail, lock, eye, eye-off) vienen de Lucide Lab / Lucide —
descargables desde lucide.dev con el mismo grid.

## brand/
logo-mark.svg — marca de la app.
El wordmark es tipográfico: "Sport" en #FFFFFF + "Match" en #4EA8FF, Inter Tight 800, tracking -0.035em.

## photos/ (7 JPG)
football-sunset, football-match, basketball-aerial, basketball-bw, streetball-bw,
tennis-clay, tennis-net. Siempre full-bleed y bajo gradiente de protección
(negro 0 → 85% de abajo hacia arriba).

## tokens/
CSS con todas las variables (color, tipografía, espaciado, radios, sombras, blur, easings).
styles.css es el entry point.

## Tipografías
Inter Tight (display / numérico) e Inter (texto) — Google Fonts.
