# SportMatch prototype

This directory is the canonical interactive prototype.

- `mobile.html`: mobile host and device frame.
- `desktop.html`: desktop screen viewer.
- `app/`: application shell, screen overrides, desktop screens, and runtime.
- `design-system/`: compiled component bundle and design tokens.
- `media/`: prototype photos, screenshots, and source uploads.

The files under `generated/figma/` are derived exports and should not be used
as the source for prototype changes.
